# STM32-based-Modbus-RTU-Multi-slave-Temperature-and-Humidity-Measurement-and-Control-System
基于STM32的Modbus-RTU主从架构温湿度测控系统

## 系统架构
整套系统包含 1 台 RS485 主机 + 2 台 Modbus 从机，实现温湿度采集、恒温控制、电机调速与全中文本地人机交互。

## 硬件组成
### 主机侧
- 主控：STM32F103C8T6
- 显示：UC1638 单色OLED液晶屏
- 字库：SPI 接口汉字库芯片，支持中文界面渲染
- 通信：RS485 总线接口
- 存储：FRAM 铁电存储器，参数掉电永久保存
- 输入：按键矩阵

### 从机侧
- 从机1：HZ8706 温湿度变送器
- 从机2：STM32 主控 + PTC 加热片 + 继电器驱动 + DHT11 温湿度采集 + 直流减速电机 + 旋转编码器

## 软件功能
### 主机功能
1. Modbus-RTU 主机协议，错峰轮询双从机；支持功能码 03H 读寄存器、06H 单寄存器写入
2. UC1638 底层驱动编写、多级菜单 UI，局部刷新，支持按键交互
3. SPI 汉字库芯片驱动，实现全中文界面显示
4. FRAM 掉电存储：保存报警阈值、目标温度、权限密码、系统配置
5. 独立看门狗 IWDG，通信故障实时检测与状态指示
6. 本地参数缓存机制：总线通信异常时，用户设定值不丢失

### 从机功能
1. Modbus-RTU 从机协议，响应主机读写寄存器指令
2. PID 恒温闭环控制，继电器驱动 PTC 加热片
3. 直流电机转速闭环控制
4. DHT11 温湿度实时采集与数据滤波
5. Flash 掉电存储

## 项目难点
1. RS485 多从机总线时序调试，解决轮询冲突与通信不稳定问题
2. 从机 PID 参数整定，实现恒温动态控制
3. UC1638 局部刷新机制，优化菜单操作流畅度
4. 主从参数本地缓存设计，通信故障不影响本地设定与运行
5. SPI 汉字库芯片驱动，实现高效中文界面渲染
